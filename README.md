# 株式会社ノースリンク コーポレートサイト（架空）

IT・Web制作会社「株式会社ノースリンク」を想定したコーポレートサイトです。
BtoB向けに、白ベース × ネイビーで「信頼感」と「読みやすさ」を重視して制作しました。

> ※ 会社名・人名・住所・電話番号・実績はすべて架空です。画像はすべて自作のダミー（SVG）です。

## 公開URL

- サイト：https://neco3-beep.github.io/northlink-corporate/
- ソースコード：https://github.com/Neco3-beep/northlink-corporate

※ 架空の企業サイトのため、全ページに `noindex` を設定し、検索結果には表示されないようにしています。

## 工夫した点

### 1. 下層ページの共通テンプレート化
全下層ページを「①ページタイトル帯 → ②パンくずリスト → ③本文エリア → お問い合わせ導線」で統一しました。
HTMLコメントで①〜③の区切りを明示し、テンプレートを使い回していることがひと目で分かる構成にしています。
表（`info-table`）・カード（`work-card` / `column-card`）・見出し（`section__head`）などの部品も、複数ページで共通利用しています。

### 2. 保守しやすいCSS設計
- クラス名は **BEM**（`block__element--modifier`）で統一
- 色・余白・文字サイズは `:root` の **CSS変数** で一元管理し、ブレークポイントごとに変数の値だけを上書き
- **モバイルファースト**で記述し、`768px`（タブレット）と `1280px`（PC）で段階的にレイアウトを変更
- コラム本文（`.post__body`）だけは、CMSで入力される本文を想定して要素セレクタでスタイルを当てています

### 3. アクセシビリティ
- 「本文へスキップ」リンク、`:focus-visible` によるはっきりしたフォーカス表示
- 背景が濃い場所ではフォーカス枠の色を変数で切り替え、どこでも見えるように調整
- 文字色は背景とのコントラスト比 4.5:1 以上になる色を選定
- ハンバーガーメニュー：`aria-expanded` で開閉状態を伝え、Escキーで閉じる／開いている間はフォーカスをメニュー内に閉じ込める
- FAQ：`<button>` と `aria-expanded` で実装。**JSが無効でも回答が読める**よう、JSが動いたときだけ閉じる作り
- フォーム：エラー文を `aria-describedby` で入力欄と関連付け、送信時は件数を `role="alert"` で通知して最初のエラー項目へフォーカス移動
- 「動きを減らす」設定（`prefers-reduced-motion`）のユーザーにはアニメーション・スムーズスクロールを無効化

### 4. SEO
- 全ページで title／description を個別に設定し、OGP・canonical も記述
- TOPに会社情報（Organization）、下層にパンくず（BreadcrumbList）、コラム詳細に記事（BlogPosting）の構造化データ
- 見出しは各ページ h1 を1つにし、階層を飛ばさない構成
- コラム詳細は記事タイトルを h1 にするため、タイトル帯の「コラム」は `<p>` にしています

### 5. JavaScriptの動き
| 機能 | 実装のポイント |
| --- | --- |
| ハンバーガーメニュー | PC幅に広げたら自動で閉じる／背景スクロールを停止 |
| ヘッダー固定＋影 | `position: sticky` で固定し、スクロール量に応じてJSで影を付与（`requestAnimationFrame` で負荷軽減） |
| スムーズスクロール | ヘッダーの高さ分のずれは CSS の `scroll-margin-top` で調整。移動先にフォーカスも移動 |
| FAQアコーディオン | `grid-template-rows` のアニメーションで高さを自然に開閉 |
| フォームの入力チェック | 入力欄から離れたとき・送信時にチェック。エラー表示中は修正した瞬間に再チェック |

## 公開時に差し替えが必要なもの

- `images/` 内のダミー画像（同じファイル名で上書きすれば差し替え完了）
- OGP画像 `images/ogp.png`（元データは `ogp.svg`。1200×630px）
- 独自ドメインで公開する場合は、canonical・OGP・構造化データのURL（現在は GitHub Pages のURL）を変更
- 本番公開時は、全ページの `<meta name="robots" content="noindex">` を削除
- 会社概要の地図枠（`.access__map`）を Googleマップの `iframe` に差し替え
- お問い合わせフォームの送信処理（現在はデモとして完了メッセージを表示するのみ）
- コラム一覧のリンク先とページネーション（デモのため全記事が `column-detail.html` にリンク）
